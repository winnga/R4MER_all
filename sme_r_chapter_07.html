8.2 Theoretical Background

Understanding Bias and Sensitivity Analysis

Before we test how bias affects our results, let’s understand what bias is and why we need to study it. Bias is one of the most important threats to validity in epidemiological research (Rothman, Huybrechts, & Murray, 2024; Dohoo, Martin, & Stryhn, 2012):

8.2.1 What is Bias?

Bias is a systematic error that makes our results wrong (Rothman, Huybrechts, & Murray, 2024; Dohoo, Martin, & Stryhn, 2012). Unlike random error (which averages out), bias consistently pushes results in one direction. Think of it like a scale that’s always off by 2 pounds - it’s consistently wrong, not just sometimes wrong.

8.2.2 Types of Bias in Research

8.2.3 1. Selection Bias

Selection bias happens when the people in your study aren’t representative of the population. Like: - Only including people who are easy to reach - Cases and controls being selected differently - People dropping out in a non-random way

Example: If you only study people who come to the clinic, you might miss people who are too sick to come. This biases your results.

8.2.4 2. Information Bias (Misclassification)

Information bias happens when you measure things incorrectly. Like: - A test that sometimes says “disease” when there’s no disease (false positive) - A test that sometimes says “no disease” when there is disease (false negative) - People misremembering their exposure

Example: If your diagnostic test is only 80% accurate, 20% of your results are wrong, which biases your estimates.

8.2.5 Why We Can’t Always Fix Bias

Sometimes we can’t measure or fix bias directly. For example: - We might not know how accurate a test really is - We might not know who was excluded from the study - We might not be able to redo the study

8.2.6 Sensitivity Analysis: Testing “What If?”

Sensitivity analysis asks: “What if there was bias? How would that change our results?” (Dohoo, Martin, & Stryhn, 2012; Rothman, Huybrechts, & Murray, 2024). It’s like stress-testing your conclusions.

Key questions: - How much bias would it take to change our conclusion? - If the test was only 70% accurate, would we still find an association? - If selection probabilities were different, would our results hold?

8.2.7 Types of Sensitivity Analysis

8.2.8 1. Deterministic (Fixed Values)

We test specific scenarios: “What if the test sensitivity was 0.8 and specificity was 0.9?” This gives us a range of possible results under specific assumptions.

8.2.9 2. Probabilistic (Simulation)

We test many scenarios by randomly sampling from ranges of possible values. Like: “If sensitivity could be anywhere from 0.7 to 0.9, what would our results look like?” This gives us a distribution of possible results.

8.2.10 Why Sensitivity Analysis Matters

Sensitivity analysis helps us: - Understand robustness: Are our conclusions fragile or robust? - Quantify uncertainty: How much does bias uncertainty affect our results? - Guide interpretation: Should we be cautious or confident in our conclusions?

In simple terms: Bias makes our results wrong in a systematic way. We can’t always fix it, but we can test how much it would affect our results. Sensitivity analysis is like asking “what if?” - it helps us understand how robust our conclusions are. If small amounts of bias would change our conclusion, we should be cautious. If our conclusion holds even with substantial bias, we can be more confident.

8.3 Helper Functions

What is this section doing?

This section sets up helper functions for sensitivity analysis. Think of it like creating tools to test how robust our results are:

  1. Observed table: The data we actually collected (cases vs controls, exposed vs unexposed)
  2. Adjustment functions: Tools to see what the results would be if we corrected for bias
  3. Simulation functions: Tools to test many different scenarios

In simple terms: We’re creating tools to answer “what if our study had bias? How would that change our results?” This helps us understand how confident we can be in our findings.

library(dplyr)
library(tidyr)
library(purrr)
library(ggplot2)
library(glue)

obs_table <- matrix(
  c(31, 16, 25, 30),
  nrow = 2,
  byrow = TRUE,
  dimnames = list(
    Case = c("Yes", "No"),
    Exposure = c("Yes", "No")
  )
)

calc_or <- function(tab) {
  (tab[1, 1] / tab[1, 2]) / (tab[2, 1] / tab[2, 2])
}

rtriang <- function(n, min, mode, max) {
  u <- runif(n)
  c <- (mode - min) / (max - min)
  result <- ifelse(
    u < c,
    min + sqrt(u * (max - min) * (mode - min)),
    max - sqrt((1 - u) * (max - min) * (max - mode))
  )
  result
}

adjust_selection <- function(sel_probs) {
  a <- obs_table[1, 1] / sel_probs$dpscex
  b <- obs_table[1, 2] / sel_probs$dpscun
  c <- obs_table[2, 1] / sel_probs$dpsnex
  d <- obs_table[2, 2] / sel_probs$dpsnun
  matrix(c(a, b, c, d), nrow = 2, byrow = TRUE)
}

solve_true_counts <- function(a_obs, b_obs, se, sp) {
  coef_matrix <- matrix(c(se, 1 - sp, 1 - se, sp), nrow = 2, byrow = TRUE)
  rhs <- c(a_obs, b_obs)
  sol <- solve(coef_matrix, rhs)
  names(sol) <- c("true_exposed", "true_unexposed")
  sol
}

adjust_misclassification <- function(parms) {
  case_true <- solve_true_counts(
    a_obs = obs_table[1, 1],
    b_obs = obs_table[1, 2],
    se = parms$dseca,
    sp = parms$dspca
  )
  control_true <- solve_true_counts(
    a_obs = obs_table[2, 1],
    b_obs = obs_table[2, 2],
    se = parms$dsenc,
    sp = parms$dspnc
  )
  matrix(
    c(case_true, control_true),
    nrow = 2,
    byrow = TRUE,
    dimnames = list(
      Case = c("Yes", "No"),
      Exposure = c("Yes", "No")
    )
  )
}

observed_or <- calc_or(obs_table)
glue("Observed odds ratio: {round(observed_or, 3)}")
Observed odds ratio: 2.325

8.4 Exercise 12.2: Selection Bias

What is this section doing?

This section examines selection bias - when the people in your study aren’t representative of the population. Think of it like a survey where only certain types of people respond:

  1. Fixed probabilities: We test what happens if we assume specific selection probabilities (like “cases who were exposed were 50% more likely to be included”)
  2. Simulation: We test many different scenarios to see the range of possible results
  3. Adjusted results: We see what the true association might be after correcting for selection bias

In simple terms: Selection bias happens when some people are more likely to be in your study than others. This section shows how that might affect your results and what the true association might be.

sel_fixed <- adjust_selection(
  list(
    dpscex = 0.5,
    dpscun = 0.6,
    dpsnex = 0.05,
    dpsnun = 0.10
  )
)

or_fixed <- calc_or(sel_fixed)
glue("Adjusted OR (fixed selection probabilities): {round(or_fixed, 3)}")
Adjusted OR (fixed selection probabilities): 1.395
set.seed(76543)
n_sim <- 2000

sel_sim <- tibble(
  dpscex = rtriang(n_sim, 0.4, 0.5, 0.6),
  dpscun = rtriang(n_sim, 0.5, 0.6, 0.7),
  dpsnex = rtriang(n_sim, 0.01, 0.05, 0.10),
  dpsnun = rtriang(n_sim, 0.05, 0.10, 0.20)
) |>
  mutate(
    adjusted_or = pmap_dbl(
      list(dpscex, dpscun, dpsnex, dpsnun),
      ~ {
        tab <- adjust_selection(
          list(dpscex = ..1, dpscun = ..2, dpsnex = ..3, dpsnun = ..4)
        )
        calc_or(tab)
      }
    )
  )

sel_summary <- sel_sim |>
  summarise(
    mean_or = mean(adjusted_or),
    median_or = median(adjusted_or),
    q025 = quantile(adjusted_or, 0.025),
    q975 = quantile(adjusted_or, 0.975)
  )

sel_summary
