2.1 Overview

This chapter provides a comprehensive introduction to R programming in the context of epidemiological research. We explore the history of R, its setup and configuration, the evolution of epidemiology, and the bidirectional relationship between epidemiology and R computing.

2.2 A Brief History of R

R is a programming language and environment for statistical computing and graphics. It was created by Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand, in 1993. The name “R” comes from the first letters of the creators’ names and is also a play on the name of the S language, which R was designed to emulate and improve upon.

2.2.1 Key Milestones in R’s Development

  • 1993: R was first conceived as an open-source alternative to S-PLUS
  • 1995: R was released under the GNU General Public License, making it freely available
  • 1997: The R Core Team was formed to coordinate development
  • 2000: R version 1.0.0 was released, marking its official stable release
  • 2004: The Comprehensive R Archive Network (CRAN) was established, providing a centralized repository for R packages
  • 2013: RStudio was released, providing a user-friendly integrated development environment (IDE)
  • Present: R has become one of the most widely used statistical programming languages, with over 20,000 packages available on CRAN

2.2.2 Why R for Epidemiology?

R has become particularly popular in epidemiology and public health research for several reasons:

  1. Open-source and free: No licensing costs, making it accessible to researchers worldwide
  2. Extensive statistical capabilities: Comprehensive tools for data analysis, modeling, and visualization
  3. Reproducible research: Excellent support for literate programming (R Markdown, Quarto)
  4. Active community: Large, supportive community of epidemiologists and statisticians
  5. Specialized packages: Many packages specifically designed for epidemiological analysis (e.g., survival, epiR, survey, metafor)

2.3 Setting Up R

2.3.1 Installing R

  1. Download R: Visit https://cran.r-project.org/
  2. Choose your platform: Select the appropriate version for Windows, macOS, or Linux
  3. Install: Follow the installation wizard (default settings are usually fine)
  4. Verify installation: Open R and type version to confirm

2.3.2 Setting Up RStudio

RStudio is the most popular IDE for R, providing a user-friendly interface with many helpful features.

2.3.2.1 Installation Steps:

  1. Download RStudio Desktop: Visit https://www.rstudio.com/products/rstudio/download/
  2. Install: Run the installer and follow the prompts
  3. First Launch: RStudio will automatically detect your R installation
  4. Configure: Go to Tools → Global Options to customize your environment

2.3.2.2 Key RStudio Features for Epidemiology:

  • Script Editor: Write and edit R code with syntax highlighting
  • Console: Interactive R session for immediate code execution
  • Environment Pane: View data objects, variables, and loaded packages
  • Plots Pane: Display graphs and visualizations
  • Files Pane: Navigate your project directory
  • Package Management: Easy installation and loading of packages
  • R Markdown/Quarto Support: Create reproducible documents

2.3.3 Setting Up Quarto (QMD) in RStudio

Quarto is a modern scientific and technical publishing system that works seamlessly with R.

2.3.3.1 Installation:

  1. Install Quarto: Visit https://quarto.org/docs/get-started/
  2. RStudio Integration: RStudio automatically recognizes .qmd files if Quarto is installed
  3. Verify: Create a new Quarto document (File → New File → Quarto Document)

2.3.3.2 Benefits of Quarto for Epidemiology:

  • Reproducible research: Combine code, output, and narrative in one document
  • Multiple output formats: HTML, PDF, Word, presentations
  • Version control friendly: Plain text files work well with Git
  • Collaboration: Easy to share and review with colleagues

2.3.4 Setting Up R in VS Code

Visual Studio Code (VS Code) is a lightweight, powerful code editor that supports R through extensions.

2.3.4.1 Setup Steps:

  1. Install VS Code: Download from https://code.visualstudio.com/
  2. Install R Extension:
    • Open VS Code
    • Go to Extensions (Ctrl+Shift+X or Cmd+Shift+X)
    • Search for “R” and install the official R extension by REditorSupport
  3. Install R Extension for Visual Studio Code: This provides syntax highlighting, code completion, and debugging
  4. Configure R Path:
    • Open Settings (Ctrl+, or Cmd+,)
    • Search for “r.rterm”
    • Set the path to your R executable (e.g., C:\Program Files\R\R-4.5.0\bin\R.exe on Windows)

2.3.4.2 Additional VS Code Extensions for R:

  • Quarto: For rendering .qmd files
  • R Debugger: For debugging R code
  • R LSP Client: Language server protocol support for better code intelligence

2.4 The History of Epidemiology

Epidemiology, derived from the Greek words “epi” (upon), “demos” (people), and “logos” (study), is the study of the distribution and determinants of health-related states or events in specified populations, and the application of this study to control health problems.

2.4.1 Key Historical Milestones:

2.4.1.1 Ancient Times

  • Hippocrates (460-377 BCE): First to observe environmental and behavioral factors affecting disease
  • Thucydides (460-395 BCE): Documented the plague of Athens, noting immunity in survivors

2.4.1.2 17th-18th Centuries

  • John Graunt (1620-1674): Published “Natural and Political Observations” on mortality data, considered the father of demography
  • James Lind (1716-1794): Conducted one of the first controlled clinical trials on scurvy

2.4.1.3 19th Century

  • John Snow (1813-1858): Famous for mapping cholera cases in London, establishing the field of disease mapping
  • William Farr (1807-1883): Developed vital statistics and standardized mortality rates

2.4.1.4 20th Century

  • Ronald Fisher (1890-1962): Developed statistical methods crucial for epidemiological analysis
  • Austin Bradford Hill (1897-1991): Established criteria for causal inference
  • Richard Doll and Austin Bradford Hill: Conducted landmark studies linking smoking to lung cancer
  • Framingham Heart Study (1948-present): Longest-running cardiovascular epidemiology study

2.4.1.5 Modern Era (21st Century)

  • Genomic epidemiology: Integration of genetic data with traditional epidemiological methods
  • Digital epidemiology: Use of digital data sources (social media, mobile health apps)
  • Global health surveillance: Real-time monitoring of disease outbreaks worldwide
  • COVID-19 pandemic: Accelerated development of epidemiological methods and data sharing

2.5 The Role of R in Epidemiology

R has become indispensable in modern epidemiological research for several key functions:

2.5.1 1. Data Management and Cleaning

Epidemiological datasets are often large, complex, and messy. R provides powerful tools for: - Importing data from various formats (CSV, Excel, Stata, SAS, SPSS) - Data cleaning and transformation - Handling missing data - Data validation and quality checks

2.5.2 2. Statistical Analysis

R excels at the statistical methods commonly used in epidemiology: - Descriptive statistics: Summarizing disease patterns - Inferential statistics: Hypothesis testing, confidence intervals - Regression modeling: Linear, logistic, survival, and mixed-effects models - Survey analysis: Complex survey designs and weighting - Meta-analysis: Combining results from multiple studies

2.5.3 3. Survival Analysis

R’s survival package is one of the most comprehensive tools for: - Kaplan-Meier estimation - Cox proportional hazards models - Time-varying covariates - Competing risks analysis

2.5.4 4. Spatial Epidemiology

R provides excellent tools for: - Disease mapping - Spatial clustering analysis - Geographic information systems (GIS) integration - Outbreak investigation and contact tracing visualization

2.5.5 5. Reproducible Research

R Markdown and Quarto enable: - Combining code, results, and narrative - Version control integration - Automated report generation - Sharing analyses with colleagues

2.6 The Bidirectional Relationship Between Epidemiology and R Computing

The relationship between epidemiology and R is mutually beneficial and continuously evolving:

2.6.1 How Epidemiology Has Shaped R Development

  1. Package Development: Many R packages were created specifically to address epidemiological needs:
    • survival: Survival analysis methods
    • epiR: Epidemiological analysis tools
    • survey: Complex survey analysis
    • metafor: Meta-analysis
    • spatialEco: Spatial epidemiological analysis
  2. Methodological Innovation: Epidemiologists have contributed new statistical methods that have been implemented in R:
    • Propensity score matching
    • Causal inference methods
    • Time-series analysis for surveillance
    • Network analysis for disease transmission
  3. Community Contributions: The epidemiological community has been active in:
    • Reporting bugs and suggesting improvements
    • Creating tutorials and documentation
    • Organizing conferences and workshops
    • Mentoring new users

2.6.2 How R Has Transformed Epidemiology

  1. Accessibility: R’s open-source nature has democratized epidemiological analysis, making advanced methods accessible to researchers in low-resource settings

  2. Reproducibility: R has promoted a culture of reproducible research in epidemiology, improving scientific rigor

  3. Innovation: R’s flexibility has enabled rapid development and testing of new epidemiological methods

  4. Education: R has become the standard tool for teaching epidemiological methods in many universities

  5. Collaboration: R facilitates collaboration through shared code, packages, and reproducible analyses

  6. Integration: R seamlessly integrates with other tools (databases, GIS software, web applications), enabling comprehensive epidemiological workflows
