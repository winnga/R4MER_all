Provide them in a format readable by sf (such as .shp or .gpkg) and update the file paths in the code chunks.

21.2 Theoretical Background

Understanding Spatial Data Visualization

Before we create maps, let’s understand the principles of spatial data and map-making. Spatial visualization is crucial for understanding geographic patterns in disease and health outcomes (Dohoo, Martin, & Stryhn, 2012; Rothman, Huybrechts, & Murray, 2024):

21.2.1 What is Spatial Data?

Spatial data is data that has a geographic location. Like: - Disease cases at specific locations (latitude/longitude) - Health outcomes by region (districts, provinces) - Environmental factors across areas

Key insight: Location matters! Things that are close together tend to be more similar than things far apart (spatial autocorrelation).

21.2.2 Why Visualize Spatial Data?

Maps help us: - See patterns: Visualize how disease varies across space - Identify clusters: Find areas with high or low rates - Communicate: Show results in an intuitive way - Explore: Discover relationships we might miss in tables

21.2.3 Types of Maps

21.2.4 1. Point Maps

Point maps show locations as points. Like marking each case on a map. Useful for: - Showing exact locations - Identifying clusters - Seeing spatial patterns

Think of it like: Pinning locations on a map.

21.2.5 2. Proportional Symbol Maps

Proportional symbol maps use symbol size to represent values. Like bigger dots for higher values. Useful for: - Showing magnitude at locations - Comparing values across areas

Think of it like: Using bigger dots for more important/larger values.

21.2.6 3. Choropleth Maps

Choropleth maps color regions based on values. Like darker colors for higher disease rates. Useful for: - Showing rates by region - Comparing areas - Identifying high/low areas

Think of it like: Coloring regions based on their characteristics.

21.2.7 4. Cartograms

Cartograms distort map areas to represent values. Like making regions bigger if they have more people. Useful for: - Showing population-weighted data - Emphasizing important areas

Think of it like: Stretching the map so important areas are bigger.

21.2.8 Key Concepts

21.2.9 1. Classification Methods

How do we group values into categories for coloring?

  • Equal intervals: Same-sized ranges (like 0-10, 10-20, 20-30)
  • Quantiles: Same number of areas per category
  • Natural breaks: Find natural groupings in the data
  • K-means: Cluster similar values together

21.2.10 2. Color Schemes

  • Sequential: Light to dark (for ordered data)
  • Diverging: Light in middle, dark at ends (for data with a meaningful middle)
  • Categorical: Different colors (for unordered categories)

21.2.11 3. Spatial Autocorrelation

Spatial autocorrelation means nearby areas are similar. Like: “If one district has high disease rates, nearby districts probably do too.”

Why it matters: It violates independence assumptions, so we need spatial methods.

21.2.12 Common Issues

  • Modifiable Areal Unit Problem (MAUP): Results depend on how you define regions
  • Ecological fallacy: Assuming what’s true for regions is true for individuals
  • Scale effects: Patterns look different at different scales
  • Edge effects: Areas near boundaries might be different

21.2.13 Principles of Good Maps

  1. Appropriate classification: Choose a method that makes sense for your data
  2. Clear legend: Make it easy to understand what colors/sizes mean
  3. Appropriate colors: Use colors that are accessible and meaningful
  4. Context: Include enough geographic context (boundaries, labels)
  5. Scale: Show the map at an appropriate scale

In simple terms: Spatial data has location, and location matters. Maps help us visualize patterns, identify clusters, and communicate results. Different map types (points, choropleths, cartograms) serve different purposes. We need to choose appropriate classification methods and colors to make maps that are informative and accurate. Spatial data is special because nearby things tend to be similar, which we need to account for in analysis.

21.4 Example 25.1: Point Maps of Infection Status

What is this section doing?

This section creates point maps showing infection status at different locations. Think of it like plotting cases on a map:

  1. Point maps: Maps where each location is marked with a point (like marking cities on a map)
  2. Infection status: Color-coding points to show which locations have infections
  3. Temporal patterns: Showing how infections change over time across locations

In simple terms: We’re creating maps that show where infections occur - marking each location with a point and using colors to indicate infection status. This helps visualize geographic patterns of disease.

# Example assumes you have:
# - district boundaries (multipolygons)
# - commune points with infection indicators by year

districts <- st_read("data/district_boundaries.gpkg")
communes <- st_read("data/commune_points.gpkg")

base_plot <- ggplot() +
  geom_sf(data = districts, fill = NA, colour = "grey50") +
  coord_sf() +
  labs(x = "Easting (km)", y = "Northing (km)")

# Current-year infection status
base_plot +
  geom_sf(
    data = communes,
    aes(colour = infected),
    shape = 16,
    size = 2
  ) +
  scale_colour_manual(values = c("grey60", "black"), name = "Infection status")
# Faceted view by year for 2003/04 through 2005/06
communes_year <- communes |>
  mutate(
    infection_year = case_when(
      inf_2003_4 == 1 ~ "2003/04",
      inf_2004_5 == 1 ~ "2004/05",
      inf_2005_6 == 1 ~ "2005/06",
      TRUE ~ "No infection"
    )
  )

base_plot +
  geom_sf(
    data = communes_year |> filter(infection_year != "No infection"),
    aes(fill = infection_year),
    shape = 21,
    colour = "black",
    size = 2
  ) +
  facet_wrap(~infection_year) +
  scale_fill_grey(name = "Infection period")

21.5 Example 25.2: Proportional Dot Maps

What is this section doing?

This section creates maps where dot size represents quantity. Think of it like using bigger dots for larger values:

  1. Proportional dots: Dot size represents the magnitude of a variable (like larger dots for higher density)
  2. Centroids: Using the center point of each area
  3. Visualizing density: Showing how density varies across geographic areas

In simple terms: We’re creating maps where the size of each dot represents a quantity (like chicken density). Bigger dots mean higher values. This helps visualize geographic patterns of continuous variables.

district_centroids <- st_centroid(districts) |>
  left_join(readr::read_csv("data/district_density.csv"), by = "district_id")

ggplot() +
  geom_sf(data = districts, fill = "grey95", colour = "grey70") +
  geom_sf(
    data = district_centroids,
    aes(size = chicken_density),
    shape = 21,
    fill = "grey60",
    colour = "black",
    alpha = 0.8
  ) +
  scale_size_continuous(name = "Birds per km²") +
  labs(title = "Chicken density by district")
plots <- list(
  chicken = "chicken_density",
  duck = "duck_density",
  human = "human_density"
)

purrr::imap(
  plots,
  ~ ggplot() +
    geom_sf(data = districts, fill = "grey95", colour = "grey70") +
    geom_sf(
      data = district_centroids,
      aes(size = .data[[.y]]),
      shape = 21,
      fill = "grey60",
      colour = "black"
    ) +
    scale_size_continuous(name = paste(.x, "per km²")) +
    labs(title = glue::glue("{stringr::str_to_title(.x)} density")) +
    theme(legend.position = "right")
)

21.6 Example 25.3: Choropleth Maps

What is this section doing?

This section creates choropleth maps - maps where areas are colored based on values. Think of it like coloring regions based on their characteristics:

  1. Choropleth maps: Maps where geographic areas are filled with colors representing values
  2. Different classification methods: Equal intervals, quantiles, or k-means clustering to group values
  3. Visualizing prevalence: Showing how disease prevalence varies across geographic areas

In simple terms: We’re creating maps where each region is colored based on a value (like disease prevalence). Darker colors might mean higher prevalence. Different methods group the values differently - equal intervals, quantiles, or clusters.

ggplot(districts) +
  geom_sf(aes(fill = prevalence)) +
  scale_fill_steps(n.breaks = 4, palette = "Greys", name = "Prevalence") +
  labs(title = "Prevalence (equal intervals)")
quantile_breaks <- quantile(districts$prevalence, probs = seq(0, 1, length.out = 5), na.rm = TRUE)

districts <- districts |>
  mutate(
    prevalence_q = cut(prevalence, breaks = quantile_breaks, include.lowest = TRUE)
  )

ggplot(districts) +
  geom_sf(aes(fill = prevalence_q)) +
  scale_fill_grey(name = "Prevalence (quantiles)")
km <- stats::kmeans(districts$prevalence, centers = 4)

districts <- districts |>
  mutate(prevalence_group = factor(km$cluster))

ggplot(districts) +
  geom_sf(aes(fill = prevalence_group)) +
  scale_fill_brewer(palette = "Greys", name = "Prevalence (k-means)")

21.7 Example 25.4: Cartogram Maps

What is this section doing?

This section creates cartograms - maps where area size represents a variable. Think of it like distorting a map so bigger areas represent larger values:

  1. Cartograms: Maps where geographic areas are resized based on a variable (like population)
  2. Distortion: Areas are stretched or shrunk to represent values
  3. Weighted by population: Making areas proportional to population size

In simple terms: We’re creating maps where the size of each region represents a value (like population). A small but densely populated area might be shown larger. This helps visualize data that’s related to population size.

library(cartogram)

# Cartogram weighted by population or cases
district_cart <- cartogram_cont(districts, weightvar = "population", itermax = 5)

ggplot(district_cart) +
  geom_sf(aes(fill = prevalence)) +
  scale_fill_steps(palette = "Greys", n.breaks = 4) +
  labs(title = "Cartogram of prevalence by population weight")
